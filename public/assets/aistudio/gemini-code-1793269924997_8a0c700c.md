Create a complete, responsive WhatsApp Web / WhatsApp Mobile clone as a single-page full-stack web application (HTML5, Tailwind CSS, and pure modern JavaScript). The app must look, feel, and function exactly like WhatsApp.

### 1. UI & Visual Design (Pixel-Perfect WhatsApp Theme)
- Palette:
  - Header / Primary: #075E54 (Dark Green) & #128C7E (Teal Green)
  - Background: #EFEAE2 with the classic WhatsApp doodle/subtle pattern texture
  - Outgoing Bubble: #DCF8C6 (Light Green) with read receipts (double grey / blue ticks)
  - Incoming Bubble: #FFFFFF (White) with sharp corner tail
  - Text & Accents: Dark Charcoal #111B21, Secondary text #667781, Accent #25D366
- Layout Structure:
  - Desktop View: Split screen (Left: 30-35% chat list & profile bar; Right: 65-70% active chat view).
  - Mobile View: Fluid responsive view switching between chat list screen and chat view screen with a back button.
- Top Header:
  - User avatar, name, online/last seen status, video call button, voice call button, search icon, three-dot menu icon.
- Bottom Input Bar:
  - Emoji picker button, attachment paperclip icon, text input ("Type a message"), mic icon (turns into send icon when typing).

### 2. Core Functional Features
- Multi-Chat List:
  - Pre-populate with 4–5 realistic sample chats with unread badges, timestamps, and message previews.
  - Active search filter in the search bar to filter contact names instantly.
- Messaging Mechanics:
  - Type and send messages instantly via Enter key or send button.
  - Automatic timestamp display on each message (e.g., "10:45 AM").
  - Message status ticks: single grey tick (sent) -> double grey tick (delivered) -> double blue tick (read) after a brief delay.
  - Auto-scroll to the bottom of the conversation when a new message is sent or received.
- Realistic Bot Auto-Reply:
  - Add realistic dummy replies using an automated response loop (or connected Gemini API) so the chat feels alive with realistic typing indicators ("typing...").
- Voice & Video Call Modal:
  - Include interactive Voice Call and Video Call overlay modals when the call buttons are clicked, showing call duration timer, mute, camera toggle, and end call buttons.
- Media & Audio Note Simulation:
  - Support photo attachments (file input displaying an image preview inside the bubble) and simulated voice note recording UI.

### 3. Technical Requirements
- Single-page architecture without external framework dependencies (Vanilla JS + Tailwind via CDN + Lucide / FontAwesome icons via CDN).
- Store active chats and state in localStorage so messages persist on page refresh.
- Clean, structured, well-commented code ready to run directly in the browser or WebView without compilation errors.
